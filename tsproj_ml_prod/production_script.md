# 生产环境框架完善

## 文件说明

项目根目录中的 `main_prod.py` 是我要在生产环境运行的脚本。下面是对该脚本的介绍

- (1) 程序运行的入口是 `run` 方法
- (2) `main()` 函数是本地测试的配置和入口，但目前实现的是多个日期手动滑窗测试；
- (3) 目前脚本中只实现了如下预测方法：
    - USMDO
    - USMR
    - USMD（可能还有问题）
    - USMDR（未实现）
- (4) 特征工程实现了：
    - 时间日期特征
    - 节假日特征
    - 气象特征
    - 滞后特征
    - 滞后统计特征（比较基础的功能，需要完善）
- (5) 还未对程序运行流程进行优化，USMD 运行特别慢，待解决；

## 任务目标

根据当前项目 `tsproj_ml` 中实现的基于机器学习模型的时间序列预测，对生产环境框架 `main_prod.py` 进行完善。具体要求如下：

不需要实现的功能：

1. 模型融合
2. 特征变换
3. 类别特征编码
4. 全局训练模式（跨序列联合）
5. 模型超参数调优
6. 特征选择
7. 学习率策略修改
8. 概率预测
9. 损失函数修改
10. 数据增强；

重点需要完善的功能：

1. 模型可选择（lightgbm、catboost）
2. 模型滑窗测试保持目前的结构
3. 模型预测方法覆盖
    * 单变量多步直接输出预测
    * 单变量多步直接预测
    * 单变量多步递归预测
    * 单变量多步直接递归预测
4. 模型框架脚本限定在 `tsproj_ml_prod` 目录中，`main_prod.py` 作为程序入口，类似根目录的 `main.py`；
5. 完善特征工程，尤其是高级特征的使用；
