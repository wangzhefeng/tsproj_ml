# AIDC HVAC 当前模型输入

本场景只保留单版本数据准备与A1_all模型配置。六组160份配置，加naive原版/去响应对照4份，共164份；原三楼分路旧版576份配置及对应结果已删除。

## 当前输入

目标为 `hvac_total_load_AB`；模型从 `dataset/aidc_hvac_load_5min/forecast_data/<设备口径>/route_AB/A1/` 读取。当前六组及naive/A1_all使用 `data_dr_adjusted.csv`，naive/A1_all_old保留原 `data.csv`。

既有时间窗仍为2026-04-08至2026-09-16，5min粒度。此次只迁移路径，不重算预测表、不运行正式模型。路径属于语义身份的一部分，产生新fingerprint；历史结果保持生成时身份，不自动重命名或冒充新结果。

水温流量、设备切换增强表保留，但不自动接入模型配置。A2/A3及三楼总表本轮只扩展异常/缺失处理，暂不提供新增预测输入。

## 数据资格

A1 IT为固定204点子集。估计不是真值；严格在线可用性与人工离线事件边界不同，当前评分不会自动排除估计点。新增楼栋无法可靠填补的点保留NaN，不能直接送入预测运行时。

具体方法、执行命令和审计目录见 `scripts/README.md`。
