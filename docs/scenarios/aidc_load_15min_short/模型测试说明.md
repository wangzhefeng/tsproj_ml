# aidc_load_15min_short — 模型测试思路说明

> **当前态（2026-09-25 场景收敛）**：本场景是全仓唯一保留的活动预测场景（模型测试场景），且只保留 LightGBM 配置：A/B 每路 baseline 9、add_exogenous 27、add_decomposition 27、add_endogenous_cross_route 9、add_endogenous_state 9，route_AB/add_endogenous_joint 9，合计 **171 份单模型 YAML**。非 LightGBM 模型配置与 `add_ensemble/` 组（其 Latin-square 成员引用 ST/Ridge，随成员删除失去意义）整体退役，内容从 Git 溯源。下表中含 add_ensemble 等与 V4 相关的行均为历史设计记录，非 `lgbm_*` 配置与 add_ensemble 均不在活动集；V4 配置合同、全模型矩阵与融合设计已拆至 [`历史设计记录.md`](历史设计记录.md)。

## 场景定位

| 项 | 值 | 说明 |
|---|---|---|
| 预测目标 | 15min 负荷（kW），A/B 两条供电路线独立建模 | `A/B_Loads_15min_mean_20251001_20260731.csv` |
| 预测跨度 | 16 步 = 调度时刻起未来 4h（超短期） | `horizon: 16`，以 freq 计步 |
| 调度语义 | 日内任意时刻滚动调度 | `schedule_mode: intraday`，`forecast_origin: 2026-07-31T14:00`，预测 14:00 → 17:45 |
| 回测几何 | history 5072 / train_window 1424 / 31 折 / 步长 96 | 约 52.8 天可用历史、14.8 天训练窗；每天固定 10:00 origin 预测 4h，共 31 日 |
| 评估口径 | 窗口级 MAPE/MAE，汇总用 **median**；附 Naive（昨日同时刻）对照 | R² 恒为负（4h 负荷近常数、方差极小），只看 MAPE/MAE |
| 预测模式 | 全部点预测 | `probabilistic.mode: point` |

> **与 daily/rolling 的差异**：horizon 缩短到 16 步（4h），训练窗约 14.8 天；回测改为日步长，使 31 个窗口覆盖一个月而非连续 28 小时。跨场景的 Horizon 不同，MAPE 仍不能直接等价比较。

## 数据处理

| 环节 | 做法 | 为什么需要 |
|---|---|---|
| 上游清洗 | 源层 `aidc_load_5min` 异常检测（物理边界 + spike）后聚合为 15min | 派生频率不再重复清洗，避免口径漂移 |
| 目标值 | `value` 列直用，无缩放/去趋势 | 分解策略由 `add_decomposition` 组单独消融 |
| 训练期异常处理 | 无（未声明 `train_outlier`） | 源层已清洗，训练侧不二次处理 |
| 样本权重 | 无（未声明 `sample_weight`） | 新矩阵默认等权，衰减加权属后续消融项 |

## 特征工程与分组

| 组 | 特征集（相对前一层的增量） | 数据通路 |
|---|---|---|
| `baseline` | 融合候选池 9 份 = ST/LightGBM/Ridge × Direct/Recursive/MIMO，统一使用 datetime 10 项 + target lags [1,2,3,4,8,12,16,96,192,672] + rolling [16,96,672]×(mean/std/min/max) + expanding(mean/std)，无 difference/分解；另保留 enet_direct、lgbm_direct_horizon、lgbm_direct_pointwise、lgbm_recmo 四个既有控制 | 单源 `target_history`（A/B 单路文件）；Ridge 仅额外使用 MinMax 缩放，ST 实际只消费 lag 与 day-of-week |
| `add_exogenous` | 完整版 = baseline + 气象 5 列 + 中国节假日；另设 weather-only / holiday-only Direct 控制 | 天气严格三段路径；节假日 builtin generator；完整基座覆盖七策略与 XGB |
| `add_endogenous_cross_route` | exogenous 特征集 + 对路负荷内生协变量（A 路目标 `A_load`、协变量 `B_load`，lags 同目标） | `forecasting_data/AB_Loads_*.csv` 合并宽表；协变量 `observed_past` + `provider: persistence` |
| `add_endogenous_state` | exogenous + 10 列纯本路 `state_*` 状态特征；全量 Direct 与训练窗内 SelectKBest 对照 | 删除 `state_route_diff_pct`；浅 lag 越过 origin 时显式 persistence |
| `add_decomposition` | exogenous + Direct×linear/STL、RecMO×STL、Recursive×STL | 训练窗仅约 2.1 个周周期，不配置 MSTL(96,672) |
| `add_ensemble`（历史，已退役） | 3 个 Latin 成员组 × 4 方法；每组恰含 ST/LightGBM/Ridge 与 Direct/Recursive/MIMO 各一次 | 直接引用 baseline 九个普通成员；顶层 data 与成员同为单一 target_history |
| `route_AB/add_endogenous_joint` | A/B 同时作为 target，K=2 MIMO / Recursive | 真正联合输出，不使用 peer persistence |

**天气严格信息集**：历史训练用实测（`weather_15min_20250101_20260731T1345.csv`，截断到调度前）；滑窗回测用 `weather_15min_backtest_proxy_20260101_20260731.csv`（ex-ante 代理，禁止测试期实测）；正式预测用 `weather_15min_future_proxy_20260731T1400_20260831.csv`。回测/预测天气均不含目标期实测，防止信息穿越。

**节假日**：`chinese_holiday` 为 builtin generated source（chinese-calendar 后端），走 canonical `known_future` 逐点精确匹配；覆盖范围外直接 RAISE，不静默降级。

> **short 场景 lag 注意**：lags 同时包含 1~16 步浅滞后和 96/192/672 步 safe-lag；浅滞后捕获 15min~4h 的近期自相关，日/周滞后提供周期参照，不能把整组误判为 safe-lag 配置。

## 结果目录与运行

```text
results/{pretrained_models,results_test,results_forecast}/<scenario_subpath>/<result_identity>/
```

- `scenario_subpath` = `aidc_load_15min_short/route_{A,B}/<group>` 或 `aidc_load_15min_short/route_AB/add_endogenous_joint`；
- 单模型 `result_identity` = `<strategy>-<model>-<scope>-k<K>-<fingerprint[:12]>`；ensemble = `ensemble-<method>-<scope>-k<K>-<fp[:12]>`（历史，已退役）；
- fingerprint 只取语义 payload，输出目录/并行度字段不参与。

单配置运行（`run.py` 无默认配置，必须显式指定 YAML）：

```bash
env -u PYTHONPATH .venv/bin/python run.py --config-yaml config/aidc_load_15min_short/<route>/<group>/<model>.yaml
```
