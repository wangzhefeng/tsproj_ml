# 日频受控优化实验

本目录只承载 `hongtaiyang_cesuan` 两站点的1D负荷诊断，不包含15min实验。

- `<variant>/<site>/lgbm_direct-pointwise.yaml`：每个候选均为完整物理canonical配置，不在运行时偷偷覆盖学习参数。
- `<variant>/annual_recipe.json`：严格版本化冷启动配方。官方春节结束后的0/3天过渡是明确候选假设，不是企业真实复工计划。
- 固定初筛月份2、3、6、7、10；冷启动在2月单独比较，其他因素在3、6、7、10比较。日历、L2和时间权重先正交后组合。
- 结果按变体写正式 `results/results_test/hongtaiyang_cesuan/experiments/`；partial表示诊断月份已跑，不冒充全年完成。
- 共用设置要求两站点正常月份MAE至少改善2%、RMSE不恶化超过2%。也允许各站点独立选择满足同一门槛的设置，未通过者保留基线。
- 全年复核时，正常月份（3—12月）仍需改善才推广对应15min负荷配置；不能把2月冷启动收益当作高频改进证据。不把负荷改进推广为光伏已验证。
- 禁止使用原点之后的目标数据估计正常水平、假期水平或训练权重。所有超参数选择基于本年诊断集，结论不是独立跨年泛化证据。
